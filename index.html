Ряды — политика конфиденциальности

Редакция от 3 октября 2026 года. Разработчик: SamokrylTeam.

Проекты и хранение на устройстве

Названия и цвета проектов, цели по рядам, счётчики рядов и раппортов, заметки, напоминания, история отмены и настройки сохраняются в закрытом хранилище приложения на вашем Android-устройстве. Регистрация не нужна. Разработчик не использует сервер для получения этих записей. Счётчик работает без интернета. Облачное резервное копирование данных приложения средствами Android отключено.

Удаление проекта убирает его из сохранённых проектов. Очистка данных приложения или его удаление удаляет локальные записи. Экспортированные резервные копии — отдельные файлы: они остаются после удаления проекта или приложения.

Резервные копии по вашему выбору

Экспорт и импорт используют системное окно выбора документа Android. Приложение получает доступ к выбранному файлу, а не ко всем файлам устройства. JSON-копия содержит записи проектов и не шифруется приложением. Не передавайте её другим людям, если не хотите раскрывать её содержимое.

Вы сами выбираете место сохранения. При выборе облачного файлового провайдера файл может передаваться и храниться у него согласно его собственной политике. Это отдельная обработка выбранным провайдером; приложение не отправляет резервные копии в сервис разработчика. Ненужные копии удаляйте через то хранилище, где сохранили их.

Необязательная реклама и идентификаторы

Приложение использует Yandex Mobile Ads SDK 8.5.0, без дополнительных рекламных адаптеров. Реклама выключена до вашего выбора в настройках. Автоматическая инициализация SDK отключена; ваш выбор применяется до запроса рекламы. Баннер находится на экранах проектов и настроек, но не на рабочем экране счётчика. Отказ от рекламы сохраняет доступ к счётчику, проектам, заметкам и резервным копиям.

Если вы включаете рекламу, SDK передаёт Яндексу идентификаторы устройства или приложения, включая App Set ID, когда он доступен, для рекламы и маркетинга: показа и оценки рекламы. Передача необязательна, поскольку вы можете пользоваться приложением без включения рекламы. Названия проектов, число рядов, заметки и резервные копии не передаются разработчику или Яндексу для рекламы.

В этой версии удалено разрешение рекламного идентификатора Android (AD_ID). Приложение не запрашивает местоположение; отслеживание местоположения и отчёты рекламной аналитики SDK отключены. Отсутствие AD_ID не исключает передачу других идентификаторов, включая App Set ID. Подробнее об обработке данных: политика Яндекса и описание данных Yandex Mobile Ads SDK 8.

Отключение рекламы и удаление данных

Рекламу можно выключить в настройках. Приложение уберёт баннер и перестанет запрашивать новые объявления. Выключение не удаляет данные, ранее обработанные Яндексом. Приложение не предоставляет собственного механизма удаления этих данных и не управляет хранилищем Яндекса. Вопросы о хранении и запросах в отношении данных Яндекса направляйте через контакты в его политике.

Локальные проекты удаляются внутри приложения, очисткой его данных или удалением приложения. Копии в выбранном файловом хранилище удаляются отдельно через этот провайдер. Эти действия не являются удалением ранее обработанных рекламным SDK данных.

Разрешения и защита

Приложение не запрашивает микрофон, фото, широкий доступ к файлам или местоположение. Интернет используется для необязательной рекламы; внешние ссылки открываются выбранным браузером. Согласно документации Яндекса, данные SDK шифруются при передаче через HTTPS/TLS. Это не означает шифрование экспортированного JSON-файла: его защита зависит от выбранного места хранения и провайдера.

Stitch Counter — privacy policy

Updated 3 October 2026. Developer: SamokrylTeam.

Projects and local storage

Project names, colors, row goals, row and repeat counts, notes, reminders, undo history and preferences are stored in the app's private storage on your Android device. No account is required. The developer does not operate a server that receives these project records. Counter functions work offline. Android cloud backup of app data is disabled.

Deleting a project removes it from the app's saved projects. Clearing the app's data or uninstalling removes its local records. Exported backups are separate files and remain after a project or the app is deleted.

Backups you choose

Export and import use Android's system document picker. The app accesses the selected file, rather than all files on the device. A JSON export contains project records and is not encrypted by the app. Share it only if you intend to disclose its contents.

You choose where to save it. If you select a cloud document provider, that provider may transfer and store the file under its own policy. This is separate processing by your chosen provider; the app does not upload backups to a developer-operated service. Delete unwanted copies through the storage provider where you saved them.

Optional advertising and identifiers

The app uses Yandex Mobile Ads SDK 8.5.0, without additional advertising adapters. Advertising is disabled until you choose to enable it in settings. The SDK's automatic initialization is disabled; your choice is applied before an ad is requested. Banners appear on the projects and settings screens, never on the working counter screen. Declining advertising leaves the counter, projects, notes and backup functions available.

If you enable advertising, the SDK sends device or app identifiers to Yandex, including App Set ID where available, for advertising and marketing: displaying and evaluating advertising. This transfer is optional because you can use the app without enabling advertising. Project names, row counts, notes and backups are not sent to the developer or Yandex for advertising.

This build removes the Android advertising-ID permission (AD_ID). The app does not request location; SDK location tracking and ad analytics reporting are disabled. Removing AD_ID does not eliminate other identifiers, including App Set ID. See Yandex's privacy policy and Yandex Mobile Ads SDK 8 data disclosures.

Turning ads off and deleting data

You can turn advertising off in settings. This removes the banner and prevents new ad requests by the app. It does not delete data previously processed by Yandex. The app does not provide its own mechanism for deleting that data or control Yandex's storage. Direct questions about retention and requests concerning Yandex's data through the contact options in its privacy policy.

Delete local projects in the app, clear its data or uninstall it to remove local records. Delete exported copies separately through the document provider you selected. These actions do not delete data previously processed by the advertising SDK.

Permissions and security

The app does not request microphone, photos, broad file access or location permissions. An internet connection is used for optional advertising; external links open in your chosen browser. Yandex documents encryption of SDK data in transit using HTTPS/TLS. This does not encrypt an exported JSON file: its protection depends on the location and provider you choose.

Contact and changes

Contact the selected document provider about its backup processing and Yandex about data it controls. Changes in data practices will be reflected in a revised policy and, where needed, a new in-app choice.
