Ряды — политика конфиденциальности

Редакция от 6 октября 2026 года. Публичная HTTPS-политика. Разработчик: SamokrylTeam. Приложение: Ряды / Stitch Counter, пакет com.jonkryl.stitchcounter. Контакт: jonkryl@gmail.com.

Проекты и хранение на устройстве

Названия и цвета проектов, цели по рядам, счётчики рядов и раппортов, заметки, напоминания, история отмены и настройки сохраняются в закрытом хранилище приложения на вашем Android-устройстве. Регистрация не нужна. Разработчик не использует сервер для получения этих записей. Счётчик работает без интернета. Облачное резервное копирование данных приложения средствами Android отключено.

Удаление проекта убирает его из сохранённых проектов. Очистка данных приложения или его удаление удаляет локальные записи. Экспортированные резервные копии — отдельные файлы: они остаются после удаления проекта или приложения.

Резервные копии по вашему выбору

Экспорт и импорт используют системное окно выбора документа Android. Приложение получает доступ к выбранному файлу, а не ко всем файлам устройства. JSON-копия содержит записи проектов и не шифруется приложением. Не передавайте её другим людям, если не хотите раскрывать её содержимое.

Вы сами выбираете место сохранения. При выборе облачного файлового провайдера файл может передаваться и храниться у него согласно его собственной политике. Это отдельная обработка выбранным провайдером; приложение не отправляет резервные копии в сервис разработчика. Ненужные копии удаляйте через то хранилище, где сохранили их.

Реклама и идентификаторы

Приложение использует Yandex Mobile Ads SDK 8.5.0, без дополнительных рекламных адаптеров. Баннеры всегда запрашиваются на экранах проектов и настроек, но не на рабочем экране счётчика. Отключения рекламы в приложении нет. Без соединения или доступной рекламы баннер может не загрузиться; счётчик и локальные проекты остаются доступными.

SDK передаёт Яндексу идентификаторы устройства или приложения, включая App Set ID, когда он доступен, для рекламы и маркетинга: показа и оценки рекламы. Поскольку отключения рекламы в приложении нет, этот сбор и передача заявляются как обязательные. Названия проектов, число рядов, заметки и резервные копии не предоставляются разработчику или Яндексу для рекламы.

В этой версии удалено разрешение рекламного идентификатора Android (AD_ID). Приложение не запрашивает местоположение; отслеживание местоположения и отчёты рекламной аналитики SDK отключены. Отсутствие AD_ID не исключает передачу других идентификаторов, включая App Set ID. Подробнее об обработке данных: политика Яндекса и описание данных Yandex Mobile Ads SDK 8.

Согласие на обработку рекламных персональных данных

Отдельное согласие по умолчанию выключено и меняется только после вашего явного выбора. Оно касается обработки рекламных персональных данных Яндексом в регионах, где применяется GDPR, и не включает или отключает баннеры. Автоматическая инициализация SDK отключена. Приложение передаёт сохранённое значение согласия Яндексу перед ручной инициализацией и рекламными запросами, в том числе при каждом запуске. Выбор включить рекламу в старой версии приложения не считается таким согласием.

Официальная инструкция Яндекса указывает, что персональные данные пользователей из регионов GDPR обрабатываются только при наличии согласия. Этот API не описан как всемирный переключатель неперсонализированной рекламы или любого сбора идентификаторов. Выключенное согласие не означает, что SDK нигде не собирает идентификаторы.

Согласие можно изменить в настройках. Его отзыв не убирает баннеры и не удаляет данные, ранее обработанные Яндексом. Приложение не предоставляет собственного механизма удаления этих данных и не управляет хранилищем Яндекса. Вопросы о хранении и запросах в отношении данных Яндекса направляйте через контакты в его политике.

Удаление локальных данных

Локальные проекты удаляются внутри приложения, очисткой его данных или удалением приложения. Копии в выбранном файловом хранилище удаляются отдельно через этот провайдер. Эти действия не являются удалением ранее обработанных рекламным SDK данных.

Разрешения и защита

Приложение не запрашивает микрофон, фото, широкий доступ к файлам или местоположение. Интернет используется для рекламы и статистики использования; внешние ссылки открываются выбранным браузером. Согласно документации Яндекса, данные SDK шифруются при передаче через HTTPS/TLS. Это не означает шифрование экспортированного JSON-файла: его защита зависит от выбранного места хранения и провайдера.

Статистика использования AppMetrica

В опубликованных сборках используется AppMetrica Яндекса для статистики установок, запусков, длительности сеансов и возвращений в приложение. SDK передаёт Яндексу технические сведения об устройстве, версии приложения и системы, идентификаторы приложения/установки и сеансы. Сетевые запросы раскрывают IP-адрес; Яндекс может определять по нему страну. Отслеживание геопозиции и рекламных идентификаторов в AppMetrica отключено; это не отключает отдельную обработку рекламного SDK. Автоматические отчёты о сбоях, ANR и доходах отключены. Названия проектов, счётчики рядов, заметки и резервные копии не передаются в события аналитики; пользовательские профили и собственные события с содержимым приложения не отправляются. Выбор персонализации рекламы не отключает эту отдельную статистику использования. Данные передаются через HTTPS/TLS и обрабатываются по политике Яндекса. Очистка данных приложения удаляет локальные записи, но не ранее переданные данные Яндекса; по вопросам их хранения и удаления обратитесь к Яндексу через его политику конфиденциальности или разработчику на jonkryl@gmail.com.

Stitch Counter — privacy policy

Updated 6 October 2026. Public HTTPS policy page. Developer: SamokrylTeam. App: Ряды / Stitch Counter, package com.jonkryl.stitchcounter. Contact: jonkryl@gmail.com.

Projects and local storage

Project names, colors, row goals, row and repeat counts, notes, reminders, undo history and preferences are stored in the app's private storage on your Android device. No account is required. The developer does not operate a server that receives these project records. Counter functions work offline. Android cloud backup of app data is disabled.

Deleting a project removes it from the app's saved projects. Clearing the app's data or uninstalling removes its local records. Exported backups are separate files and remain after a project or the app is deleted.

Backups you choose

Export and import use Android's system document picker. The app accesses the selected file, rather than all files on the device. A JSON export contains project records and is not encrypted by the app. Share it only if you intend to disclose its contents.

You choose where to save it. If you select a cloud document provider, that provider may transfer and store the file under its own policy. This is separate processing by your chosen provider; the app does not upload backups to a developer-operated service. Delete unwanted copies through the storage provider where you saved them.

Advertising and identifiers

The app uses Yandex Mobile Ads SDK 8.5.0, without additional advertising adapters. Banners are always requested on the projects and settings screens, never on the working counter screen. The app has no advertising opt-out. A banner may not load without a connection or available advertising; counting and local project functions remain usable.

The SDK sends device or app identifiers to Yandex, including App Set ID where available, for advertising and marketing: displaying and evaluating advertising. Because advertising has no opt-out in this app, this collection and sharing are declared required. Project names, row counts, notes and backups are not supplied to the developer or Yandex for advertising.

This build removes the Android advertising-ID permission (AD_ID). The app does not request location; SDK location tracking and ad analytics reporting are disabled. Removing AD_ID does not eliminate other identifiers, including App Set ID. See Yandex's privacy policy and Yandex Mobile Ads SDK 8 data disclosures.

Consent to advertising personal-data processing

A separate consent setting starts off and changes only after your explicit choice. It concerns Yandex's processing of advertising personal data in regions where GDPR applies; it does not turn banners on or off. The SDK's automatic initialization is disabled. The app passes the saved consent value to Yandex before manual initialization and ad requests, including at each launch. A choice to enable ads in an older app version is not treated as this consent.

Yandex's official consent guidance states that personal data from users in GDPR regions is processed only with consent. This API is not documented as a worldwide switch for nonpersonalized advertising or all identifier collection. A false value does not mean that the SDK collects no identifiers everywhere.

You can change the consent setting in Settings. Withdrawing consent does not remove banners or delete data previously processed by Yandex. The app does not provide its own mechanism for deleting that data or control Yandex's storage. Direct questions about retention and requests concerning Yandex's data through the contact options in its privacy policy.

Deleting local data

Delete local projects in the app, clear its data or uninstall it to remove local records. Delete exported copies separately through the document provider you selected. These actions do not delete data previously processed by the advertising SDK.

Permissions and security

The app does not request microphone, photos, broad file access or location permissions. An internet connection is used for advertising and usage statistics; external links open in your chosen browser. Yandex documents encryption of SDK data in transit using HTTPS/TLS. This does not encrypt an exported JSON file: its protection depends on the location and provider you choose.

Contact the selected document provider about its backup processing and Yandex about data it controls. AppMetrica usage statistics

Published builds use Yandex AppMetrica to measure installations, app launches, session duration and return visits. The SDK sends Yandex technical device, app and operating-system information, app/installation identifiers and session information. Network requests expose an IP address; Yandex can derive the country from it. AppMetrica location tracking and advertising-identifier tracking are disabled; this does not disable the separate advertising SDK processing. Automatic crash, ANR and revenue reporting are disabled. Project names, row counts, notes and backups are not sent in analytics events; no user profiles or custom events containing app content are sent. The advertising-personalization choice does not disable these separate usage statistics. Data is transmitted over HTTPS/TLS and handled under Yandex’s privacy policy. Clearing app data removes local records, but not data already sent to Yandex; contact Yandex through its privacy policy or the developer at jonkryl@gmail.com for retention and deletion questions.
